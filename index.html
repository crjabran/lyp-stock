📂 Copia de seguridad (CSV)

El stock se guarda online y se sincroniza solo entre todos los móviles y ordenadores que abran este enlace. Esta sección sirve para guardar una copia en un archivo o recuperar datos desde uno.

Exportar copia de seguridad:

  1. Ve a la pestaña 📋 Lista
  2. Pulsa 📥 Exportar CSV para guardar un archivo con el stock y los precios actuales

Restaurar desde una copia de seguridad:

  1. Arrastra el CSV aquí abajo o pulsa para seleccionarlo
  2. Se actualizan las cantidades (y precios, si el archivo los tiene) de cada modelo del archivo, para todos

🔒 Solo el administrador puede restaurar una copia de seguridad.
